# Profile mountains

The three ridgelines reuse Ihoey’s blog component:
[`FooterLandscape.astro`](https://github.com/ihoey/blog/blob/685cc4ef/src/components/FooterLandscape.astro).

The paths are unchanged; an 800-unit viewport crops the original wide landscape to keep the ridges visible in a narrow README. Explicit blue fills adapt the blog’s light and dark footer palette for standalone SVG images in GitHub READMEs. The background is transparent; no scripts, external images, fonts, or animations are required.
